# Earlier measurement set — RETIRED, kept for comparison

The CSVs in this directory were produced from the **hand-transcribed** verdicts described in
`code/raw/RUN-LOG.md`. The paper **no longer quotes a single number** from here; every number in it
comes from `tables/rerun-*.csv` and `tables/hard-corpus.csv`, which are derived from the raw logs in
`code/raw/`.

They are kept for two reasons. They are the evidence that the earlier campaign was **not
fabricated**: the cheap tier over-rejects the same valid reduction, and the moderate and lenient
rigs return 0.00 on fabricated citations, both of which reproduced. And the comparison between the
two sets is what supports the paper's point that **a measurement has a shelf life**.

**Do not use these files for any number in the paper.**
