# Producers of the retired measurement set

These scripts produced the CSVs in the parent directory, which the paper no longer cites. They are
kept for provenance: they show how the earlier numbers were derived, which is what makes the
comparison between the two campaigns checkable.

**They are not expected to run against the current layout.** Their output paths point at
`paper/tables/` and `paper/figs/`, where their CSVs no longer live. Re-pointing them would create a
second, competing set of live tables, which is precisely the ambiguity this reorganisation removed.

Anything the paper cites is produced by the scripts in `code/`, listed in `code/csv-producer.map`.
